A tiny program that writes exactly one word to `/output/entry.txt` — the
word the entrant's ex would use to describe them: **Layaway**. She put a
little down, kept him on hold in the back, and never came back to pick
him up. The word was chosen by a 16-candidate criteria-ordered
tournament against the judge's published criteria (one real word an ex
would use, laugh, sting of recognition, instant, relatable), with a
refinement round that favoured a word with zero presence in the
existing field. Output is byte-exact: 7 UTF-8 bytes, no trailing
newline. Run it with `python3 main.py`.
